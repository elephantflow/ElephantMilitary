### 1. 特朗普宣布当日再度"重击"伊朗

| 字段 | 内容 |
|------|------|
| ⏰ 时间 | 2026-06-11 约06:00（北京时间） |
| 📍 地点 | 美国华盛顿 / 伊朗境内 |
| 🏷️ 类型 | 战斗 / 外交军事声明 |

**事件详情**

美国总统特朗普在白宫椭圆形办公室向记者表示，美军已于周三（当地时间）再次对伊朗发动打击，并声称当日还将"重击"伊朗。美国中央司令部（Centcom）确认周三17:15东部时间发动了针对伊朗"多个目标"的打击，称此次行动是对"伊朗持续无端挑衅"的回应。伊朗总统佩泽什基安在X平台回应称，伊朗"将坚定面对任何压力与威胁"。伊斯兰革命卫队（IRGC）则宣称已对巴林和约旦的美军基地发起反击，美方称绝大多数伊朗导弹和无人机均被成功拦截，无人员伤亡。

**背景**

2026年2月28日，美以联合空袭伊朗并造成伊朗最高领袖身亡，触发大规模冲突。4月达成临时停火，但双方此后多次互相违反协议。6月9日，伊朗击落一架美国陆军直升机，美方随即升级打击。

### 2. 美军击伤第8艘油轮，印度3名水手失踪

| 字段 | 内容 |
|------|------|
| ⏰ 时间 | 2026-06-10（北京时间） |
| 📍 地点 | 阿曼湾 / 波斯湾 |
| 🏷️ 类型 | 战斗 / 海上封锁执法 |

**事件详情**

美国中央司令部宣布，一架美军飞机向帕劳籍油轮"塞特贝洛号"（Settebello）的机舱发射精确制导弹药，理由是该船"多次拒绝执行美军指令"并涉嫌违反针对伊朗的封锁令运输伊朗原油。印度政府表示，船上3名印度水手下落不明，21名船员已获救。印方召见美国驻德里使馆副馆长，并声明"必须停止针对商业航运和平民基础设施的袭击"。这是美军自4月13日宣布封锁伊朗港口以来击伤的第8艘船只，已改道134艘。

**背景**

伊朗此前封闭霍尔木兹海峡（全球约20%的油气供应过境），美军随后宣布海上封锁。此次事件引发印度外交抗议，折射出封锁行动的平民代价。

📎 来源：[BBC News](https://www.bbc.com/news/articles/c0rygjw1kqxo)

### 3. 以色列空袭黎巴嫩南部致17人死亡

| 字段 | 内容 |
|------|------|
| ⏰ 时间 | 2026-06-10至11日（北京时间） |
| 📍 地点 | 黎巴嫩南部（泰尔、西顿等城镇） |
| 🏷️ 类型 | 战斗 / 空袭 |

**事件详情**

据黎巴嫩国家通讯社（NNA），以色列对黎巴嫩南部发动多轮空袭和炮击，造成至少17人死亡。其中，塔伊尔代巴镇（Tayr Debba）遭受4次以上打击，9人罹难；代尔卡努恩纳赫尔村（Deir Qanoun el-Nahr）3人死亡；西顿市中心一辆汽车遭无人机定点清除，2人死亡。真主党宣布对以色列占领区内的以军士兵及车辆实施反击。联合国人权事务高级专员沃尔克·蒂尔克宣布派遣调查组赴黎，审查三月以来各方可能的战争罪行。

**背景**

黎巴嫩于2026年3月2日卷入美以伊冲突，真主党向以色列境内发射火箭弹，以色列随即发动大规模轰炸并入侵黎南部。美国主导的停火协议于4月16日达成，但冲突至今未停。截至目前，黎巴嫩已有至少3,696人死亡，近百万人流离失所。

📎 来源：[BBC News](https://www.bbc.com/news/articles/cpq3d44l907o)

|------|------|
| ⏰ 时间 | 2026-06-10（北京时间） |
| 📍 地点 | 维也纳（IAEA总部） |
| 🏷️ 类型 | 外交军事行动 / 核不扩散 |

**事件详情**

国际原子能机构（IAEA）理事会通过美国支持的决议，要求伊朗提供其铀库存及生产设施的详细信息。IAEA总干事拉斐尔·格罗西呼吁德黑兰重新接受核查人员。伊朗驻维也纳联合国使团谴责这一决议"虚伪"，批评美国在表面支持外交的同时继续"袭击伊朗平民基础设施"。IAEA此前一份战时首份报告指出，已无法核实伊朗的440.9公斤高浓缩铀库存，97天的核查空窗期阻碍了国际核保障监督。

**背景**

伊朗核计划是美伊谈判的核心议题。美以一直指控伊朗寻求发展核武器，后者坚称其核计划完全出于和平目的。

|------|------|
| ⏰ 时间 | 2026-06-10至11日夜间（北京时间） |

| 🏷️ 类型 | 战斗 / 远程精确打击 |

**事件详情**

乌克兰总统泽连斯基宣布，乌克兰FP-5"火烈鸟"巡航导弹对俄罗斯楚瓦什共和国切博克萨雷市的VNIIR-Progress军工厂实施打击，该厂专门为俄军提供无人机和导弹零部件，距前线超过900公里。此外，乌军同时打击了亚速海的俄占马里乌波尔港（该港已瘫痪）、萨马拉炼油厂以及黑海"影子舰队"油轮。俄罗斯方面确认切博克萨雷遭袭，3人受伤。"火烈鸟"导弹战斗部重达1,150公斤，射程3,000公里，可覆盖莫斯科在内的多数俄罗斯主要城市。

**背景**

近几个月来，乌克兰大幅强化对俄境内目标的长程无人机打击。FP-5导弹的投入使用标志着乌克兰深度打击能力的重大提升。

## 📊 趋势分析

过去12小时，全球军事热点高度集中于**中东战场**和**东欧战场**两条主线，并出现明显的升级迹象。

**中东方向**：美伊战局在停火协议名存实亡的状态下持续恶化。特朗普政府的军事压力与外交要价同步施加，IAEA核决议则为其提供了多边框架支撑。伊朗反击虽规模受限（多数导弹被拦截），但其信号意义不可忽视——德黑兰仍有意维持"受控升级"态势，避免全面战争。美军以封锁执法名义击伤第8艘油轮并造成印度船员伤亡，开始引发非战争方国家的反弹，印度的外交抗议值得关注。

**东欧方向**：乌克兰"火烈鸟"导弹成功打击900公里外的俄军工厂，是自战争以来最深远的精确打击行动之一，与此前对圣彼得堡油码头的无人机打击共同标志着乌方"战略纵深打击"能力的质变。克里米亚桥梁被摧毁进一步压缩俄军后勤空间，俄军正从部分前线收缩，但双方谈判尚无实质进展，普京依然拒绝一切和谈提案。

**南亚与东南亚**：巴基斯坦-阿富汗边境局势再度紧张，缅甸内战则在沉寂中重现烈度。当前多线冲突并发的格局，正测试着国际社会的危机处理承载能力上限。
